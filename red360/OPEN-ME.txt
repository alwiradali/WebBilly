360RED PRODUCTIONS — Interactive Enterprise Virtual Tour Platform
================================================================

TO VIEW IT
----------
Just double-click  index.html.  That's it — no server, no install, no build.

If you'd rather run it from VS Code:
  1. Open this folder in VS Code
  2. Install the "Live Server" extension
  3. Right-click index.html → "Open with Live Server"

WHAT'S HERE
-----------
  index.html   the shell — three screens in one page
  app.css      the design system
  app.js       the application (router, panels, search, guided tour, studio)
  engine.js    the WebGL engine (no dependencies)
  tour.js      A BUILDING — Charnwood House, the 18,500 sq ft example
  tour-ashby.js  a second building, to show it carries more than one
  README.md    full technical documentation

FIRST FIVE THINGS TO TRY
------------------------
  1. Start the tour, then click a glowing ring to walk through a doorway
  2. Press Cmd+K (Mac) or Ctrl+K (Windows) and search for "board room"
  3. Reception → left panel → "Flat panorama"
  4. Studio → Branding → drag the accent colour picker
  5. Studio → Hotspots → "Place a hotspot" → click inside the panorama

ADDING MORE PLACES AND MORE BUILDINGS
-------------------------------------
A NEW SPACE in the building you are looking at:
  Studio → Rooms → "Add space".  Name it, pick the floor, pick the type.
  It appears on the dashboard, on the floor plan and in the tour straight
  away.  Duplicate and Delete are at the bottom of the same panel.

A NEW BUILDING:
  Studio → Projects → "New project"  (or "Duplicate this project", or
  "Import a tour.json").  Switch between buildings from the button at the
  top of the dashboard, or with Cmd+K.

  Those live in your browser.  To ship one to everybody:
    1. Studio → Publish → "Export tour.json"
    2. Save it into this folder as  tour-<name>.js  and wrap it:

         (window.RED360_TOURS = window.RED360_TOURS || []).push(
           { ...the exported JSON... }
         );

    3. Add one line to index.html, next to the others:

         <script src="tour-<name>.js"></script>

  That is the whole deployment step. No build, no database, no rebuild.

IF SOMETHING GOES WRONG
-----------------------
The page always tells you what happened — it never just hangs.

Older graphics chips can't compile the full 3D renderer. The engine detects
that and drops to a simpler one automatically, remembering the choice. You can
also force it by adding to the address:

  ?tier=1   simpler renderer
  ?tier=2   simplest renderer — works on anything that runs WebGL
  ?q=lo     smaller panoramas, for slower machines

If the screen stays black, hardware acceleration is switched off:
  Edge/Chrome → Settings → System → "Use graphics acceleration when available"
Turn it on and restart the browser.
