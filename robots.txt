# Billy Digitals — robots.txt
# Search engines: full access to public pages.
#
# Private paths are repeated in every group below. robots.txt has no
# inheritance: a crawler obeys ONLY the most specific group that matches its
# name, so a named agent with just "Allow: /" ignores the "*" rules entirely.
# Without the repeats, every client demo under /templates/ was crawlable by the
# AI agents even though it was disallowed for everyone else.
#
# Disallow lines come before "Allow: /" in each group on purpose. Modern
# crawlers resolve conflicts by longest match (RFC 9309) and would block either
# way; older first-match parsers only block if the Disallow is listed first.

User-agent: *
Disallow: /templates/
Disallow: /send-review.html
Disallow: /admin.html
Allow: /
